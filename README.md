# Passarela · do roteiro à experiência

Apresentação do jogo de totem *Passarela* (Transitolândia · DER-DF / Convergint, jogo 4 de 5): do roteiro do DER à experiência final.

Abra `index.html` ou a página publicada. Navegue com as setas do teclado; F = tela cheia. No celular em pé, os slides viram uma coluna que se rola com o dedo.
